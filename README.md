# PLL Wavelet Analysis Toolkit

A modern Python-based reimplementation and extension of my graduate thesis work on
injection-locked oscillators and wavelet-based time-frequency analysis.

This project includes:
- Digital PLL simulation
- Injection locking models
- Phase noise and jitter analysis
- Wavelet transforms (Morlet, CWT, synchrosqueezed)
- Denoising comparisons
- Jupyter notebooks for reproducible research

This repository serves as both a learning resource and a practical mixed-signal engineering project.
